# Pickup Ticker Icons

Place the PNGs from this folder next to `xinput1_3.dll` (in `Bin32/`).

The ticker loads these real item images (sourced from evilresource.com). There is no procedural fallback.

Run `download-icons.sh` to fetch them, or copy the files directly.

## Files
- handgun-ammo.png, shotgun-ammo.png, rifle-ammo.png, magnum-ammo.png, tmp-ammo.png, handcannon-ammo.png
- hand-grenade.png, incendiary-grenade.png, flash-grenade.png
- green-herb.png, red-herb.png, yellow-herb.png
- first-aid-spray.png
- white-egg.png, brown-egg.png, gold-egg.png
- black-bass.png
- pesetas.png

Source: https://www.evilresource.com/images/data/full/re4/
