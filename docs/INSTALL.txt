RE4 Modern Controls
===================

Modern controls for the original Resident Evil 4 (2005, Steam). Controller only.

INSTALL
-------
Windows:              double-click install.bat
Linux / Steam Deck:   run install.sh (Desktop Mode: right-click > Run in Konsole)

The installer finds Resident Evil 4 in your Steam libraries, installs the mod,
asks a few questions about the controls (press Enter for the recommended
settings) and, on Linux, sets up Proton to load the mod. Then start the game
from Steam as usual. Run the installer again any time to change the settings.

Manual install: copy files/xinput1_3.dll into the game's Bin32 folder
(Steam > right-click Resident Evil 4 > Manage > Browse local files).
On Linux / Steam Deck also set the launch option:
    WINEDLLOVERRIDES="xinput1_3=n,b" %command%

CONTROLS
--------
Left stick      Leon moves where you push it, relative to the camera
                (he runs; hold the game's run button to walk)
Right stick     Free camera, stays where you leave it
Aim             Leon turns to where the camera looks
  Left stick    walk while aiming
  Right stick   aim (a crosshair marks where the laser points)

UNINSTALL
---------
Windows: install.bat -Uninstall      Linux / Steam Deck: ./install.sh --uninstall

SETTINGS
--------
The installer covers the main choices. Fine-tuning lives in
Bin32\RE4ModernControls.ini, which explains every option (changes apply while
the game runs). An in-game settings page is planned.
