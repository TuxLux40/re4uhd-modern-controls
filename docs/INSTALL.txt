RE4 Modern Controls
===================

Modern controls for the original Resident Evil 4 (2005, Steam). Controller only.

INSTALL
-------
1. In Steam, right-click Resident Evil 4 > Manage > Browse local files.
   A folder named "Resident Evil 4" opens (it contains the "Bin32" folder).
2. Extract this zip into that folder. Allow it to merge with the existing
   "Bin32" folder. The file xinput1_3.dll ends up next to bio4.exe.
3. Windows: done, start the game.

   Linux / Steam Deck (Proton) only: right-click Resident Evil 4 > Properties >
   Launch Options and paste:

       WINEDLLOVERRIDES="xinput1_3=n,b" %command%

   If you also use re4_tweaks, paste this instead:

       WINEDLLOVERRIDES="dinput8,xinput1_3=n,b" %command%

CONTROLS
--------
Left stick      Leon moves where you push it, relative to the camera
                (he runs; hold the game's run button to walk)
Right stick     Free camera, stays where you leave it
Aim             Leon turns to where the camera looks
  Left stick    walk while aiming
  Right stick   aim

UNINSTALL
---------
Delete Bin32\xinput1_3.dll (and RE4ModernControls.ini / .log next to it).
Linux: also remove the launch option.

SETTINGS
--------
Everything works with the defaults. An in-game settings page is planned.
Until then, advanced settings live in Bin32\RE4ModernControls.ini, which the
mod creates on the first start (changes apply while the game runs).
